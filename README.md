# NOIR — Monochrome Experimental Portfolio

React + TypeScript + Vite portfolio implementing the requested black-and-white overlapping-card aesthetic.

## Run
npm install
npm run dev

## Build
npm run build

## Customize
Edit `src/main.tsx` to replace the name, bio, email and social links. Edit the `projects` array near the top of the same file to add/remove projects.

The demo artwork is generated entirely with CSS so the project runs immediately. Replace the `Art` component with real `<img>` assets when you have your project thumbnails.
